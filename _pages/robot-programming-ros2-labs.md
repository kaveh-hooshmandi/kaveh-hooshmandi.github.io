# Practical labs

These are proposed lab themes. Handouts, files, dates, and submission requirements will be added before each lab is assigned.

| Lab | Goal | Suggested deliverable |
|---:|---|---|
| 1 | Set up a workspace and inspect a running ROS 2 system | Workspace notes and command output |
| 2 | Create a Python publisher and subscriber | Package source and a short demonstration |
| 3 | Add a service or action to a robot task | Working client/server pair and explanation |
| 4 | Configure nodes with parameters and a launch file | Reproducible launch package |
| 5 | Visualize robot frames and a description | Frame diagram and model screenshot |
| 6 | Integrate nodes in simulation | Demonstration and troubleshooting report |

## Lab submission template

For each lab, provide the objective, environment and software version, setup steps, source files, evidence of a working result, and a brief reflection on problems encountered.

**Lab handouts and deadlines:** To be announced.
