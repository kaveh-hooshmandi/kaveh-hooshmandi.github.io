## What you will learn

The planned learning outcomes are to:

1. Create and manage a ROS 2 workspace and packages.
2. Write Python nodes that publish and subscribe to topics.
3. Use services, actions, and parameters for robot behavior.
4. Launch and inspect multi-node systems with command-line tools.
5. Work with robot descriptions, coordinate frames, and simulation.
6. Document, test, and demonstrate a small integrated robot application.
