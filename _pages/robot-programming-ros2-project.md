# Course project

The proposed project is a small robot application that combines multiple ROS 2 components. The final topic, team size, milestones, and due date will be announced with the official brief.

## Suggested project structure

1. Define a clear robot task and expected behavior.
2. Draw the node graph and identify the required interfaces.
3. Implement the nodes and configuration in a ROS 2 package.
4. Demonstrate the application in simulation or on approved hardware.
5. Record results, explain limitations, and document how to reproduce the demonstration.

## Proposed deliverables

- Source code and launch instructions.
- A short technical report with architecture, test procedure, results, and limitations.
- A live or recorded demonstration.
