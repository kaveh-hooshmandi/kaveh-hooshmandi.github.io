## Description

Students develop robot software with ROS 2 through short programming tasks and practical integration work. The proposed scope covers workspaces and packages, nodes, communication interfaces, launch and configuration, coordinate frames, robot descriptions, and simulation.

## Prerequisites

Basic Python programming and familiarity with terminal commands are recommended. Any formal prerequisite will be announced before enrollment.

## Learning outcomes

By the end of the course, students should be able to create a ROS 2 package, implement communicating nodes, choose suitable communication interfaces, inspect a running system, and demonstrate a documented robot application.
