# Assignments

No assignments have been published yet. Each assignment will include its task, expected files, evaluation criteria, due date, and submission link.

## Planned assignment themes

1. **ROS graph inspection:** Identify nodes, topics, services, and message types in a running example.
2. **Communication package:** Implement and explain a publisher/subscriber pair, then extend it with a service or action.
3. **Robot application:** Launch and diagnose a small multi-node workflow.

These themes are provisional; the official briefs and deadlines will appear here.
