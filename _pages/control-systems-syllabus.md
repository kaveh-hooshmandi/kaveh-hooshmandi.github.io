# Syllabus: Applied Control Systems

## Course description

This course covers the analysis, design, implementation, and testing of feedback control systems. It begins with classical control concepts and progresses toward PID control, motion control, embedded implementation, and robotics applications.

## Prerequisites

Students should have basic knowledge of:

- Engineering mathematics
- Differential equations or dynamic systems
- Basic electronics and sensors
- Introductory programming in C, Python, or MATLAB

## Assessment plan

| Component | Weight | Description |
|---|---:|---|
| Weekly quizzes | 10% | Short formative checks on key concepts |
| Assignments | 25% | Analysis and simulation tasks |
| Laboratory work | 25% | Practical setup, measurement, implementation, and reporting |
| Final project | 25% | Design and test a controller for a practical system |
| Oral/demo assessment | 15% | Explain, demonstrate, and defend the implemented solution |

## Practical skill rubric

| Criterion | Excellent performance |
|---|---|
| Setup and wiring | Correct, safe, organised, and well documented |
| Measurement | Accurate data collection with suitable sampling and units |
| Controller design | Clear justification of controller type and parameters |
| Troubleshooting | Identifies faults logically and tests possible causes |
| Interpretation | Connects results to theory and performance specifications |
| Report quality | Clear structure, figures, tables, and engineering conclusions |

## Weekly plan

| Week | Lecture topic | Lab / activity |
|---:|---|---|
| 1 | What is feedback control? | Identify control loops in real systems |
| 2 | Mathematical models | Model a first-order thermal system |
| 3 | Transfer functions | Simulate transfer functions in Python/MATLAB |
| 4 | Transient response | Measure overshoot, rise time, and settling time |
| 5 | Stability | Apply Routh-Hurwitz criterion |
| 6 | Root locus | Design a gain for transient performance |
| 7 | Frequency response | Interpret Bode plots and bandwidth |
| 8 | PID control | Tune P, PI, and PID controllers |
| 9 | Digital control | Convert a continuous PID idea into discrete code |
| 10 | Motor control | DC motor speed and position control |
| 11 | Embedded control | STM32/Arduino implementation activity |
| 12 | Robotics control | Mobile robot velocity and heading control |

## Main deliverables

1. Completed lab notebooks or worksheets.
2. Simulation files for selected assignments.
3. Final project report with design, implementation, results, and discussion.
4. Short demonstration or oral explanation of the final controller.
