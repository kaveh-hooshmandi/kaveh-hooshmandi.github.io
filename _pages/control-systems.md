# Applied Control Systems
### From Feedback Theory to Robotics, Embedded Control, and Industrial Automation

This open course introduces feedback control from first principles and connects the theory to real engineering implementation. It is designed for undergraduate engineering students who need both analytical understanding and practical laboratory skills.

## Course aim

The aim of this course is to help students analyse, design, implement, test, and evaluate feedback control systems used in automation, robotics, embedded systems, and smart manufacturing.

The course is intentionally practical: every major topic includes a simulation activity, a laboratory task, or a real engineering example such as DC motor speed control, position control, temperature control, or mobile robot motion control.

## Learning outcomes

By the end of the course, students should be able to:

1. Explain the difference between open-loop and closed-loop control systems.
2. Model simple dynamic systems using transfer functions and block diagrams.
3. Analyse transient response, steady-state error, damping, overshoot, rise time, and settling time.
4. Design and tune PID controllers for process and motion-control applications.
5. Use simulation tools to evaluate time-domain and frequency-domain performance.
6. Implement a simple digital control loop on embedded hardware.
7. Test, troubleshoot, and report practical control-system performance.

## Weekly roadmap

| Week | Topic | Practical connection |
|---:|---|---|
| 1 | Introduction to control systems | Open-loop vs closed-loop examples |
| 2 | Mathematical modelling | DC motor and thermal plant models |
| 3 | Transfer functions and block diagrams | Block reduction and simulation |
| 4 | Transient response | Rise time, overshoot, settling time |
| 5 | Stability and Routh-Hurwitz | Stability checking before implementation |
| 6 | Root locus design | Controller gain selection |
| 7 | Frequency response and Bode plots | Bandwidth and robustness |
| 8 | PID control and tuning | Process and motor PID design |
| 9 | Digital control and sampling | Discrete PID implementation |
| 10 | DC motor speed and position control | Encoder feedback and PWM |
| 11 | Embedded control with STM32/Arduino | Real-time controller implementation |
| 12 | Robotics motion control | ROS2 mobile robot control example |

## Teaching approach

The course uses short lectures, worked examples, practical demonstrations, laboratory worksheets, formative quizzes, and a final applied project. Students are assessed not only on final numerical answers but also on engineering process: correct setup, safe operation, data collection, troubleshooting, interpretation, and technical reporting.

## Suggested external references

- Norman S. Nise, *Control Systems Engineering*.
- William Bolton, *Instrumentation and Control Systems*.
- Online simulation tools: MATLAB/Simulink, Python Control Systems Library, and ROS2/Gazebo.
