# Schedule and topic outline

The sequence below is a draft. Session dates, readings, and links to slides will be added when the course calendar is confirmed.

| Unit | Topic | Suggested practice |
|---:|---|---|
| 1 | ROS 2 environment and command-line tools | Read [Ubuntu Terminal Basics (PDF)](/courses/robot-programming-ros2/materials/ubuntu_linux_terminal_basics.pdf), then run and inspect example nodes |
| 2 | Workspaces, packages, and Python nodes | Create a package and run a node |
| 3 | Topics and message types | Build a publisher and subscriber |
| 4 | Services and actions | Implement request/response and long-running tasks |
| 5 | Parameters, names, and launch files | Configure and start multiple nodes |
| 6 | Logging, introspection, and recorded data | Diagnose and replay robot behavior |
| 7 | Coordinate frames and robot description | View robot frames and a basic model |
| 8 | Simulation and sensor data | Connect a simulated robot to ROS 2 nodes |
| 9 | Integration and debugging | Combine components into a working application |
| 10 | Project demonstration | Present and discuss the completed system |
